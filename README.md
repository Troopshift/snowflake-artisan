# Snowflake Artisan

This is a **Vibe Coding** project created and deployed through AI Studio. It is a specialized tool for generating radial symmetry and fractal patterns.

**Project Link:** [AI Studio App](https://ai.studio/apps/29ef1eca-6c23-4544-9592-20a1d17dc571)

## Run Locally

**Prerequisites:** Node.js

1. **Install dependencies:**
   `npm install`

2. **Set API Key:**
   Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key.

3. **Run the app:**
   `npm run dev`

## Deployment

Built with **Vite**

* **Environment:** Node.js 24
* **Base Path:** `./`
